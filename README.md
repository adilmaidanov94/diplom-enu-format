# diplom-enu-format

Скилл для Claude: оформление дипломной работы (проекта) в формате .docx по Положению ЕНУ им. Л.Н. Гумилёва ПОЛ ЕНУ 2.014-KV (ред. 31.08.2026).

## Что делает

- поля 30/10/20/25 мм, Times New Roman 14, одинарный интервал, абзацный отступ 1,25 см;
- удаляет пустые абзацы и ручные разрывы страниц, каждый раздел начинает с новой страницы;
- приводит заголовки, подписи рисунков («Рисунок N. Название» / «N-сурет. Атауы») и таблиц к требованиям Положения;
- проверяет ссылки в тексте на рисунки, таблицы и формулы, порядок и число источников, URL/DOI;
- нумерует страницы с «Введения»;
- постранично верстает документ: ни одна страница не начинается с рисунка, таблицы или формулы, перенос таблицы оформляется подписью «Продолжение таблицы N» (каз. «N-кестенің жалғасы»).

Поддерживаются работы на русском, казахском и английском языках.

## Состав

| Файл | Назначение |
|---|---|
| `SKILL.md` | инструкция для Claude (скрипты включены в неё полностью) |
| `scripts/vkr_format.py` | форматирование документа и отчёт о замечаниях |
| `scripts/vkr_layout.py` | постраничная вёрстка через рендер LibreOffice |

## Запуск скриптов вручную

```bash
pip install python-docx pymupdf      # нужен также LibreOffice (soffice) с модулем Math
python3 scripts/vkr_format.py input.docx step1.docx --report fmt.json
python3 scripts/vkr_layout.py step1.docx final.docx --kind work --pdf preview.pdf --report layout.json
```
